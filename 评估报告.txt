P2G V2 当前评估报告
====================

项目名称
--------
P2G V2（长文 PDF 结构化理解与证据问答系统）

生成时间
--------
2026-08-16

目标
----
评估当前版本在 PDF 结构识别、章节去噪、事实抽取、证据汇总、答案生成与 token 效率方面的实际效果。

一、当前能力
------------

1. 结构理解：目录、图注、提示词转储、图片 OCR 文本等噪声在建树前剥离；章节层级归一化；小体积碎片子节并入父节（子节标题保留，小节号仍能锚定证据）。
2. 事实抽取：每块输出有上限，抽取与归纳阶段首次调用关闭思考，输出稳定落在预算内，实测截断率为 0；事实带原文引用、页码与置信度，可定位回原文。
3. 表格净化：配置表数值行与跨列碎片表头噪声在事实库源头剔除，不再进入证据索引。
4. 指标回收：`kind="metric"` 不再只依赖 markdown 表格解析。表格为空时由抽取提示词（正文指标标注）与 `extract_metric_facts` 确定性兜底两条路径补齐，指标类问题不再因证据池为空而答非所问。
5. 证据问答：10 项全局问答按句子粒度审计证据，答案全部中文转述、禁止粘贴原文，英文泄漏有确定性兜底；"矛盾"问题确定性列出跨章节冲突并附页码；证据不足时保守作答。
6. token 效率：抽取与归纳阶段关闭思考后，流水线 reasoning token 消耗趋近于 0，reduce 族总 token 下降约三成，无质量回退。

二、实测验证情况
---------------

- 多篇不同形态的 PDF（实验论文、英文综述、结构较乱的中译综述）全流程实测：10/10 全局问答零幻觉、零英文泄漏、答案带可定位页码出处。
- 截断与恢复：抽取与归纳阶段实测截断 0 次、恢复调用 0 次（修复前抽取约 37.5%、归纳约 42%）。
- token：reduce 族 reasoning token 由约 134K 降至约 0.3K（仅保留思考的总览除外），总 token 降幅约 34%。
- 单元测试 103 个全部通过。

三、仍存在的问题
---------------

1. 纯图表内文字随图片 OCR 一起剥离，不再入事实库；待用图表密集的论文验证是否削弱"图表内容"类问题的回答。（指标类问题已由正文兜底路径覆盖，但仅存在于图表、正文从未提及的数值仍会丢失。）
2. "未来工作"问题偶发仍混入方法实现描述，检索层可再收紧事实 kind 白名单。
3. 高层摘要为事实拼接式归纳，连贯性仍有提升空间。
4. 概述层文档标题偶发误译（属采样波动）。

四、结论
--------

当前版本已具备较完整的"结构理解 → 事实抽取 → 分层归纳 → 证据问答"能力，在多种形态 PDF 上实测零幻觉、零英文泄漏、答案带出处，token 消耗与截断恢复率已从源头降到可忽略水平。剩余问题集中在收尾，不影响主流场景使用。
