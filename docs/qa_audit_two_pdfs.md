## 发现的主要失效模式

1. **答案完整性未被自动指标反映。** 两篇均有“比较对象”误拒答；实验论文另外两道表格题也误拒答。自动引用可解析率仍为 1.0。
2. **表格结构解析不稳。** `Learning to Share` 的表 1 事实中，跨列表头被拆成 `Assist ... / antBe / nch` 和 `GA ... / IA`，Qwen3-32B 的模型名拆成 `Qen3`、`w (32B)`。这会破坏检索和数值比较，但不能单独证明每次拒答都由表格解析造成。
3. **问题类型缺少约束。** 综述论文的“指标/定量结果”需要区分论文提出的评估框架与被引用研究的实验数字；“矛盾”需要明确区分真实冲突与设计权衡。
4. **引用检查只验证局部可追溯性。** 可解析事实 ID 不等于答案完整、切题或数值自洽，尤其不能把“证据不足”自动视为正确。

## 下一步优先级

先用这 20 题作为固定回归样本。优先修复表格行列和数值关系的结构化解析，再检查问答候选事实覆盖率与拒答门槛；为“评价指标”“比较对象”“定量结果”“跨章节矛盾”加入不同的核对规则。每次改动后用相同两份 PDF 和逐题人工标准对照，分别统计正确、部分正确、误拒答、错答，不能只看 `unsupported_claim_rate`。
